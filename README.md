# Tickrate

[![CI](https://github.com/DannSant/tickrate/actions/workflows/ci.yml/badge.svg)](https://github.com/DannSant/tickrate/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An authoritative real-time multiplayer game backend in Java 21 and Spring Boot: skill-based matchmaking, fixed-tick game rooms over WebSockets, Glicko-2 ratings and a live leaderboard.

> **Work in progress.** This README grows with the project; the full version will cover the architecture, design decisions and how to run it.

## Build

Requires JDK 21. The Gradle wrapper downloads the right Gradle version on first run.

```bash
./gradlew build
```
